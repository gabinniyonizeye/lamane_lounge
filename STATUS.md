## 🚀 How to Start (3 Steps)

### Step 1: Open 3 PowerShell Windows

### Step 2: Terminal 1 - MongoDB
```powershell
cd "C:\Program Files\MongoDB\Server\7.0\bin"
.\mongod.exe
```

### Step 3: Terminal 2 - Backend
```powershell
cd "d:\my_website\LAMANE project\lamane_bakery_coffee"
npm run dev:server
```

### Step 4: Terminal 3 - Frontend
```powershell
cd "d:\my_website\LAMANE project\lamane_bakery_coffee"
npm run dev
```

### Step 5: Browser
```
http://localhost:5173
```
